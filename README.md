# 慧行 WiseWalk

一款给汉传佛教在家居士的定课记录 App。念佛、持咒、诵经、拜佛、打坐——记下来，仅此而已。

**iOS 17.4+ · SwiftUI · 无广告 · 无内购 · 无账号 · 永久免费**

---

## 发心

这是**法布施**。不收费，不放广告，不收集任何数据，不求回报。

## 为什么它不会哪天弄丢你的功课

调研了 1214 条同类 App 的真实评论后发现，用户最深的一处焦虑不是功能不够，而是**记录没了**——换手机没了、登录不上没了、服务器关了没了。

有一款 App 的用户在评论区互相提醒：开发者说项目在商业上没有盈利方式也没有后续融资，请师兄们及时备份，以防服务器突然关闭。

**所以慧行没有服务器。**

- 你的功课存在**你自己的 iCloud** 里，不经过任何第三方
- 我看不到你的任何数据，也不想看到
- 没有服务器就没有服务器费用，**唯一的成本是每年 99 美元的开发者账号，且和用多少人无关**
- 数据随时可完整导出，你想走随时能带走全部记录

我不做服务器，所以我永远不会因为撑不下去而弄丢你的功课。

## 一些刻意的取舍

| 不做 | 为什么 |
|---|---|
| 广告 | — |
| 账号登录 | 不需要，也不想知道你是谁 |
| 共修排行榜 | 修行不是比赛 |
| 连续天数当主指标 | 连续 200 天断掉那一刻的焦虑，正是要避免的。主指标是**累计**，只增不减 |
| 运营推送 | 只有你自己设的提醒。不发功能公告，不发节日营销 |
| 赞赏 / 供养入口 | App Store 内打赏须走内购，苹果抽三成，说不过去。想随喜的话，**转给需要的人**就是最好的随喜 |

还有一个**隐藏模式**：熄屏般的纯黑界面，只留一个极暗的数字。给那些不方便让同事和家人知道自己在念佛的人。

## 关于代码

### 许可：GPL-3.0

代码一并布施。任何人可以 fork、研究、自用。

### 不接受 Pull Request

这一条**不是**嫌麻烦，是法律上的必需，说明如下：

GPL-3.0 与 App Store 的条款是冲突的（VLC 曾于 2011 年因此被下架）。之所以官方版本仍能上架，是因为**版权人不受自己所授许可的约束**——我拥有全部版权，才能一边以 GPL-3.0 开源，一边照常上架。

一旦合并了他人的代码，我就不再是唯一版权人，**自己上架反而变成侵权**。

因此：

- **不接受 PR**，不承诺回复 issue
- 欢迎 fork 自用，欢迎照着做一个自己的
- 但**你 fork 出去的版本无法上架 App Store**——这不是我设的限制，是 GPL 与苹果条款的既有冲突

发现 bug 欢迎开 issue 告诉我，我会看，但不保证回复。**尤其是任何可能导致数据丢失的问题，请一定告诉我。**

### 如果哪天我不做了

代码在这里，GPL-3.0，谁都可以接着做。

已经装了的人不会被远程删掉，数据在自己的 iCloud 里，随时能导出。这是开源的意义。
